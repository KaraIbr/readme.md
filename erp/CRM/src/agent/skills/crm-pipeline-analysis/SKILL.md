# CRM Pipeline Analysis

Use this skill for questions about current stage, stage history, elapsed time, status, won/lost state, or pipeline movement.

1. Retrieve pipeline summaries or transitions for the relevant lead or proposal.
2. Use transition timestamps for elapsed time.
3. Distinguish lead stages from proposal stages.
4. Do not infer a win or loss unless the lead or proposal stage/outcome explicitly says so.
5. If transition history is missing, say that no transition history was found.
