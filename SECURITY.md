# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Contact:** [k210240.i@gmail.com](mailto:k210240.i@gmail.com)

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response

You can expect an initial acknowledgement within 48 hours. We will work with you to understand and address the issue before any public disclosure.

## Scope

This policy applies to the Ventura Energy platform codebase hosted in this repository.

## Guidelines

- Do not exploit vulnerabilities beyond what is necessary to demonstrate the issue.
- Do not access or modify data belonging to other users.
- Report issues privately via email before discussing them publicly.
